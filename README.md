# Colloqui scuola-famiglia – IIS "Francesco Ciusa" Nuoro

Pagina pubblica per consultare, classe per classe, i docenti e la loro collocazione durante i colloqui scuola-famiglia.

- Sito: https://eleonoramecarelli-sketch.github.io/colloqui-ciusa/
- Link diretto a una classe: `?classe=4C`

I dati non sono in questo repository: la pagina li legge a ogni apertura dal foglio Google dell'Istituto,
tramite l'app Google Apps Script collegata (`?formato=json`). Per aggiornare docenti, collocazioni, data e orario
si modifica soltanto il foglio Google.
